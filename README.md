# Giga Limit - دليل التشغيل

Giga Limit برنامج محلي لتحديد ومتابعة استهلاك الإنترنت للموبايلات المتصلة على نفس شبكة Wi-Fi. لا تحتاج إلى خبرة برمجية أو تثبيت Node.js أو Flutter أو Android Studio.

## ما الذي ستنزله؟

نزّل الملفين الجاهزين التاليين وضعهما في نفس المجلد:

- [تحميل برنامج السيرفر لـWindows: GigaLimit_Server.exe](https://github.com/yousef-812/GigaLimit/releases/latest/download/GigaLimit_Server.exe)
- [تحميل تطبيق Android: GigaLimit_App.apk](https://github.com/yousef-812/GigaLimit/releases/latest/download/GigaLimit_App.apk)

يمكنك أيضاً فتح [صفحة كل الإصدارات](https://github.com/yousef-812/GigaLimit/releases) إذا احتجت إصداراً أقدم.

```text
GigaLimit_Server.exe
GigaLimit_App.apk
```

ضع الملفين في **نفس المجلد** على جهاز Windows الذي سيتحول إلى سيرفر. لا تغيّر اسم أي ملف.

مثال:

```text
GigaLimit\
  GigaLimit_Server.exe
  GigaLimit_App.apk
```

لا يحتاج المستخدم العادي إلى تنزيل المشروع أو بنائه من المصدر.

## قبل التشغيل

1. استخدم جهاز Windows متصل بالراوتر نفسه الذي تتصل به الموبايلات.
2. اترك الجهاز مشغلاً طالما تريد أن يعمل الإنترنت المحكوم بالحصص.
3. يفضّل تعطيل Sleep للجهاز حتى لا يتوقف السيرفر.
4. تأكد أن شبكة Windows مضبوطة على **Private network** وليست Public.

## تشغيل السيرفر

1. افتح مجلد `GigaLimit`.
2. اضغط مرتين على `GigaLimit_Server.exe`.
3. إذا ظهر طلب من Windows Firewall، اختر **Allow access** على **Private networks**.
4. اترك نافذة السيرفر مفتوحة. إغلاقها يوقف السيرفر والـVPN للمستخدمين.
5. لمعرفة عنوان IP الخاص بجهاز السيرفر، افتح نافذة السيرفر. ستجد رابط لوحة الإدارة مثل:

```text
https://192.168.100.84:3000
```

هذا هو العنوان الذي سيكتبه المستخدمون في التطبيق.

## فتح لوحة الإدارة

من جهاز السيرفر أو من أي هاتف على نفس الشبكة، افتح الرابط الظاهر في نافذة السيرفر:

```text
https://IP-OF-SERVER:3000
```

قد يظهر تحذير من المتصفح لأن الشهادة محلية. اختر المتابعة إلى الموقع داخل الشبكة المحلية.

### كلمة مرور الإدارة

عند أول تشغيل ينشئ السيرفر كلمة مرور عشوائية. ستجدها في الملف:

```text
admin_credentials.txt
```

هذا الملف يتولد تلقائياً بجانب `GigaLimit_Server.exe`. افتحه لتعرف كلمة المرور، واحتفظ به في مكان آمن. لا تظهر كلمة المرور في نافذة السيرفر.

## تثبيت التطبيق على الهاتف

1. انقل `GigaLimit_App.apk` إلى هاتف Android، أو افتح هذا الرابط من الهاتف:

```text
https://IP-OF-SERVER:3000/download_app
```

2. ثبّت التطبيق. إذا طلب Android السماح بالتثبيت من مصدر غير معروف، اسمح للتطبيق الذي فتحت منه ملف APK.
3. افتح تطبيق **Giga Limit**.
4. اكتب اسم المستخدم.
5. اكتب IP جهاز السيرفر، مثال: `192.168.100.84`.
6. اضغط الاتصال، ثم وافق على إذن VPN والإشعارات.
7. اضغط زر VPN داخل التطبيق لتوجيه الإنترنت عبر السيرفر وحساب الاستهلاك.

كل مستخدم يحتاج تطبيقه الخاص وجهازه الخاص. لا تكتب IP الموبايل، اكتب IP جهاز Windows الذي عليه `GigaLimit_Server.exe`.

## إدارة المستخدمين

من لوحة الإدارة تستطيع:

- مشاهدة الأجهزة المسجلة واستهلاك كل جهاز.
- تغيير الحد اليومي والأسبوعي.
- حظر جهاز أو جعله Unlimited.
- تجديد حصة اليوم أو الأسبوع.
- إرسال إشعار للمستخدم.
- حذف مستخدم.

عند تغيير هاتف المستخدم من شبكة إلى أخرى، VPN يرسل IP الجديد تلقائياً إلى السيرفر خلال ثوانٍ. لا يلزم فتح التطبيق مرة أخرى طالما إشعار VPN ما زال ظاهراً.

## لا تحذف هذه الملفات

بعد تشغيل السيرفر ستظهر ملفات إضافية في نفس المجلد:

| الملف | وظيفته |
| --- | --- |
| `giga_limit_db.json` | قاعدة البيانات الأساسية: المستخدمون والإعدادات والاستهلاك. |
| `giga_limit_db.json.bak` | نسخة احتياطية كاملة تتحدث كل ساعة. |
| `admin_credentials.txt` | كلمة مرور لوحة الإدارة. |
| `server.key` و`server.cert` | شهادة الاتصال المحلي. |
| `vpn_debug.log` | سجل تشخيص VPN. يحتفظ بآخر 1000 سطر فقط. |

لا تحذف أو تنقل هذه الملفات. إذا كان الملف الأساسي لقاعدة البيانات فارغاً أو تالفاً بعد انقطاع الكهرباء، يستعيد السيرفر البيانات تلقائياً من `giga_limit_db.json.bak` عند التشغيل التالي، بما في ذلك الأجهزة والاستهلاك.

لعمل نسخة أمان يدوية: أغلق السيرفر أولاً، ثم انسخ مجلد `GigaLimit` كاملاً إلى USB أو Google Drive.

## المشاكل الشائعة

| المشكلة | الحل |
| --- | --- |
| التطبيق لا يجد السيرفر | تأكد أن الموبايل والجهاز على نفس Wi-Fi وأنك كتبت IP جهاز Windows الصحيح. |
| التطبيق متصل وVPN يعمل لكن لا يوجد إنترنت | تأكد أن نافذة السيرفر مفتوحة، ثم اسمح لـ`GigaLimit_Server.exe` في Windows Firewall على Private networks. |
| لا يمكن فتح لوحة الإدارة | جرّب الرابط من جهاز السيرفر نفسه أولاً، ثم تأكد من أن المنفذ `3000` غير محجوز. |
| لا أعرف كلمة مرور الإدارة | افتح `admin_credentials.txt` بجانب EXE. |
| تغيرت شبكة الهاتف ولا يعمل الإنترنت | انتظر عدة ثوانٍ مع بقاء VPN متصلاً. إذا استمر الخطأ، أوقف VPN وشغله مرة أخرى. |
| السيرفر أغلق فجأة | شغله مرة أخرى من `GigaLimit_Server.exe`. قاعدة البيانات والنسخة الاحتياطية تبقيان في نفس المجلد. |

## للمسؤول عن التوزيع فقط

المستخدمون العاديون يحتاجون فقط إلى الملفين الجاهزين. عند إصدار نسخة جديدة، انشر `GigaLimit_Server.exe` و`GigaLimit_App.apk` معاً في صفحة Releases، وبنفس الأسماء، حتى يستطيع المستخدم اتباع الخطوات أعلاه.
